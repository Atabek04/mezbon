# Mezbon

**Mezbon** (uz. *мезбон*, "host") is a multilingual LLM sales agent that grounds every answer in a real catalog,
guides customers through order details, and closes sales on WhatsApp and Telegram. Like the one who greets guests at
the door, it welcomes each customer and looks after them until the order is placed.

The first deployment is a bakery. Early development; this repo ships a demo catalog only.
